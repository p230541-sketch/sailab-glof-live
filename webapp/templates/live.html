Live check

Check for a new scene now

Runs the real pipeline once for every lake that already has stored data, exactly as the nightly run does: it asks Google Earth Engine for Sentinel-2 scenes newer than the last stored one, checks the cloud over each lake, downloads and measures any clear scene, and scores it. It needs an internet connection.

Results are written to this laptop's working copy of the database only, never to the published record that the nightly run commits. From October to May these lakes are usually cloudy, frozen or snow-covered, so "no usable observation" is the most likely honest result.
